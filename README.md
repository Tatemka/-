# 🐱 КОТОСТЬ МАРКЕТ (Kotost Market)

**КОТОСТЬ МАРКЕТ** — это полноценный IoT-проект для автоматизации заказов, созданный на базе **CyberPi** (Makeblock) и **Raspberry Pi** (DietPi). 

Проект работает **полностью локально**: нажатие кнопки на контроллере или клик на сайте отправляет TCP-пакет на малинку, которая сохраняет заказ в базу данных SQLite и пересылает уведомление на локальный сервер `ntfy` (без использования интернета).

---

## 🏗️ Архитектура проекта

1.  **Клиент (CyberPi)**: Подключается к Wi-Fi. При нажатии кнопки **B** отправляет TCP-пакет `ЗАКАЗ КОТОСТИ` на IP-адрес сервера.
2.  **Сервер (Raspberry Pi / DietPi)**: 
    *   Написан на **Python 3**.
    *   Работает как служба `systemd` (автозапуск при включении).
    *   Слушает порты `5050` и `5051`.
    *   Принимает пакеты, корректно обрабатывает кодировку (UTF-8) и отправляет POST-запрос на локальный `ntfy`.
    *   **Автоочистка:** При достижении 20 заказов база данных полностью очищается, и счёт начинается с 1.
3.  **Веб-интерфейс (Flask)**:
    *   Написан на Python (Flask).
    *   Работает на порту `8080`.
    *   Показывает историю заказов в тёмной теме.
    *   Позволяет заказать котость или очистить базу прямо из браузера.
4.  **Уведомления (Локальный ntfy)**:
    *   Развернут на самом Raspberry Pi (порт `80`).
    *   Показывает уведомления в браузере (`http://192.168.1.140/kotost-market`).
    *   Может отправлять Push-уведомления на телефон через приложение ntfy.

---

## 🚀 Особенности (Features)

*   **100% локальность**: Не требует интернета, все данные внутри вашей сети.
*   **Автономность**: Сервер работает как демон, не требуя SSH-подключения.
*   **Умная очистка**: База данных не переполняется, автоматически очищаясь при достижении 20 записей.
*   **Веб-интерфейс**: Тёмная тема, красивые карточки и управление заказами.
*   **Поддержка кириллицы**: Русские буквы передаются без ошибок `latin-1`.

## 🛠️ Установка и настройка

### 1. Установка локального ntfy
Скачиваем бинарник с GitHub и запускаем:
```bash
wget https://github.com/binwiederhier/ntfy/releases/download/v2.34.0/ntfy_2.34.0_linux_arm64.tar.gz
tar zxvf ntfy_2.34.0_linux_arm64.tar.gz
sudo cp ntfy_2.34.0_linux_arm64/ntfy /usr/bin/
