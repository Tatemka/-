# 🐱 КОТОСТЬ МАРКЕТ (Kotost Market)

**КОТОСТЬ МАРКЕТ** — это IoT-проект для автоматизации заказов, созданный на базе **CyberPi** (Makeblock) и **Raspberry Pi** (DietPi). 

Нажатие кнопки на портативном контроллере мгновенно отправляет заказ на сервер (Raspberry Pi), который перенаправляет его в облачный сервис уведомлений. В результате — вы получаете Push-уведомление на компьютер или телефон за доли секунды.

---

## 🏗️ Архитектура проекта

Система состоит из трех ключевых компонентов:

1.  **Клиент (CyberPi)**:
    *   Подключается к Wi-Fi.
    *   При нажатии кнопки **B** отправляет TCP-пакет `ЗАКАЗ КОТОСТИ` на IP-адрес сервера.
2.  **Сервер (Raspberry Pi / DietPi)**:
    *   Написан на **Python 3**.
    *   Работает как служба `systemd` (круглосуточно, с автозапуском при включении).
    *   Слушает порты `5050` и `5051`.
    *   Принимает TCP-пакеты, обрабатывает кодировку (UTF-8) и отправляет POST-запрос в API.
3.  **Уведомления (ntfy.sh)**:
    *   Облачный сервис доставки Push-уведомлений.
    *   Доставляет сообщения на ПК (браузер) и смартфоны.
